# MC体力清图 · 梦境博览会 DEMO V1.6

依据2026-09-23《【MC】【活动】体力清图活动策划文档》更新。广场与五区、17点剧情、任务手册、房间扭蛋及通关循环均可体验。

## 打开

- 双击「梦境博览会-即开即玩.html」可离线体验，无需安装。
- 模块版运行 `npm start`，访问 `http://localhost:4173`；PORT环境变量可改端口。
- `npm test` 运行规则测试；`npm run build` 从源码重建离线单文件。
- 运行时零第三方依赖，静态分发需保留 `src/`、`assets/`、`styles.css`、`index.html`。

## 本轮更新

- 按房间随机不放回抽取，房间抽空再进入下一房；×1/3/5/10逐项读取。
- 重复玩具按品质返活动体力，取消重复积点和免费抽入口。
- 每段清障随机掉券，落地后飞入入口；本图全部宝箱可预览。
- 五区域各3件合集，加五木马合集；全收集奖为Wild卡。已领任务压暗沉底。
- 六区域地图入口、两人对白、5秒推进、材料提交确认、首次引导。
- P17后末区循环小径可重复；不重复增加剧情和合集进度。
- 到期继续停留可用活动内资源；退出后清空活动体力与券。未领地图箱不补；已达成手册及玩具奖励经补发弹板手动领取。

操作说明见 [Demo体验说明.md](./Demo体验说明.md)，变更与暂定口径见 [V1.6修改清单.md](./V1.6修改清单.md)，参数边界见 [实现对照与评审假设.md](./实现对照与评审假设.md)。V1.4/V1.5清单仅为历史记录。

## 存档

存档保存在当前浏览器。自动读取V1.5/V1.2旧存档，保留地图、剧情、木马、已领奖记录和资源；已拥有但不再属于三件合集的材料保留其地图完成记录。旧免费次数按单抽券价转为券，旧未满重复点只留迁移记录，不擅自折算新体力。旧未确认抽奖批次仍显示原结果，不重抽。

新抽奖启用本期持久化房间种子、房间号与位置。切换倍率、关闭界面和重进不会重置剩余奖池。跨版本首次使用新房间时，从新房间池开始，既有玩具与已领奖状态保留。

## 接入边界

本地DEMO不连接真实账号、服务器、订单、支付、PopupsOrder或主棋盘。等级/订单波次/软硬关与时间均由评审工具模拟；主线道具在本地待领奖记录承接。真实资格校验、两天结算期由正式服务接入实现。

文档时长存在9天/13天及会前8天差异，本版暂按9.1.1的9天。正式房间配置、R0～R10换算、费用和产销比未提供；当前奖励数量与地图费用用于功能评审，未视作9天正式数值节奏。
