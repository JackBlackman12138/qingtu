# 梦境博览会 · 可玩 DEMO V1.5

依据最新修订的《梦境博览会_体力清图活动策划文档》。包含中央广场、五个区域、17个剧情点、六条任务手册合集，以及扭蛋、体力、回城安装、存档和结算。

## 即开即玩

双击 **梦境博览会-即开即玩.html**，在 Edge / Chrome 中直接体验，无需安装或联网。进度保存在当前浏览器；移动或改名可能改变文件存储范围。

模块版 `index.html` 需通过 HTTP 服务打开。安装 Node.js 后运行 `npm start`，访问 `http://localhost:4173`；可通过 PORT 环境变量指定端口。运行时零第三方依赖。

## 本版流程

1. 清障进入广场，完成P01，第一条云雾路径露出传送门。
2. 进入区域，清障、免费拾取固定道具；道路和材料齐备后自动修复并播放短对白。
3. 末点对白结束，木马原地出现。点击领取才完成本区末点，随后仍留在本区。
4. 主动通过传送门回广场，自动安装木马并开放下一区。第五匹安装后完成P17。
5. 五个区域分别组成合集，五匹木马组成第六条合集。六份合集奖和全收集奖独立领取；手册6/6不要求剧情17/17。

## 代码与验证

- `npm test`：18项规则测试，含完整通关、独立领奖、自动修复、旧存档迁移及1000组扭蛋倍率拆分一致性。
- `npm run build`：从源码重新生成即开即玩单文件。
- `src/config.js`：地图、合集条目、费用、奖励和扭蛋序列。
- `src/state.js`：初始状态、存档读写和旧版迁移。
- `src/game-engine.js`：资源、剧情、收集和结算规则。
- `src/map-view.js`：目标揭露、路径点、缩放边界和收集变化。
- `src/components.js`、`src/main.js`、`styles.css`：界面、输入和反馈。
- `src/art.js`：原创SVG插画。

体验方式见 [Demo体验说明.md](./Demo体验说明.md)，改动说明见 [V1.5修改清单.md](./V1.5修改清单.md)。V1.4修改清单仅作历史记录。

## 存档与接入范围

旧版进度自动迁移；已完成剧情对应的物品补入手册，已领取的旧手册奖励按同类资源抵扣新版奖励，避免重复发放。旧存档仍保留。尚未领取的木马保持待领取。

没有真实支付、账号云存档、服务器资格判定或MergeCooking订单接入。评审工具用于模拟订单与时间。R0～R10正式换算、正式商品和结算比例仍待配置。主路7800、支路1800、剧情体力箱1200沿用试算；六合集及总奖体力200，扭蛋收藏奖另200。

静态分发保持 `index.html`、`styles.css`、`src/`、`assets/` 相对目录；也可只分享单文件HTML。
