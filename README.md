# 梦境博览会 · 可玩 DEMO

依据《梦境博览会_体力清图活动策划_V1.2》。包含中央广场、五个区域和完整 17 点剧情，以及清障、手册、收藏、扭蛋、体力、回城安装、存档和结算。

## 即开即玩

双击 **梦境博览会-即开即玩.html**，在 Edge / Chrome 中直接体验，无需安装或联网。进度保存在当前浏览器。移动或改名后浏览器可能采用新的文件存储范围；建议保持入口位置稳定。

模块版 `index.html` 需要 HTTP 服务，不能直接双击运行模块。

## 工程启动

需要已安装 Node.js，运行 `npm start`，打开 `http://localhost:4173`。运行时零第三方依赖，无安装、构建步骤。默认端口 4173，可通过 PORT 环境变量调整。

- `npm test`：状态引擎验证，含完整通关和1000组倍率拆分一致性。
- `node build-standalone.cjs`：修改源码后重新生成单文件版。
- `src/config.js`：地图费用、阶段节点、奖励、扭蛋序列与体验参数。
- `src/state.js`：初始状态、存档键、读写。
- `src/game-engine.js`：唯一规则引擎，所有资源与进度修改。
- `src/art.js`：原创 SVG 插画与场景。
- `src/components.js`：主界面、弹窗和状态显示。
- `src/main.js`：输入、动画、存档调度与独立评审操作。

## 评审方式

先按正常路径体验广场入口、第一次清障与 P01。再用齿轮「评审工具」中的「下一剧情点前」快速检查后续内容；剧情、标记、木马仍需手动完成。可以模拟订单、推进时间、断网、归零体力、结束活动、导出存档或重置。

优先阅读 [Demo体验说明.md](./Demo体验说明.md) 和 [实现对照与评审假设.md](./实现对照与评审假设.md)。后者列明已确认规则、试算值和接入范围。

## 静态分发

工程可交给普通静态 HTTP 服务，保持 `index.html`、`styles.css`、`src/`、`assets/` 相对目录。也可只分享单文件 HTML。`.nojekyll` 已包含。本轮没有提交远端仓库或发布公网网站。

## 本地模拟边界

没有真实支付、账号云存档、服务器资格判定、MergeCooking 主棋盘或订单接入。主线奖励用本地账户记录，订单按独立评审事件模拟。角色绘本插画不是正式项目立绘。数值沿用文档试算及明确标识的体验配置；R0～R10 正式公式留空。体力结算金币比例未配置时保留审计记录，不猜测兑换量。
